# GXWorks3 バイナリエディタ 操作手順まとめ

## 背景・目的

- バイナリエディタのUIコントロールを作成する依頼があり、操作感・挙動を確認するために使用
- GXWorks3はインストール済み（別端末）

---

## サンプルファイルについて

- `.gx3` 形式のサンプルファイルは、三菱電機FAサイトからダウンロード可能だが **FAメンバーズへの登録が必要**
- 操作確認だけであれば、**新規プロジェクト作成で代用可能**（ファイルは不要）

---

## 手順1：GXWorks3を起動する

1. Windowsの **スタートメニュー** を開く
2. 検索欄に `GXWorks3` と入力
3. 「**MELSOFT GXWorks3**」が表示されたらクリック
4. スプラッシュ画面（ロゴ）が表示される
5. しばらく待つとメイン画面が開く

---

## 手順2：新規プロジェクトを作成する

1. 画面上部のメニューバーから **「プロジェクト」** をクリック
2. ドロップダウンから **「新規作成」** をクリック
3. ダイアログが表示されるので以下を設定する
   - **シリーズ**：`RCPU`
   - **機種**：`R00CPU`
   - **言語**：`ラダー`（デフォルトのままでOK）
4. 右下の **「OK」** をクリック
5. ラダーエディタ画面が開く

---

## 手順3：バイナリエディタを開く

1. 画面上部のメニューバーから **「ツール」** をクリック
2. ドロップダウンから **「バイナリエディタ」** をクリック
3. バイナリエディタ画面が開く

---

## バイナリエディタの基本操作

| 操作 | 挙動 |
|------|------|
| アドレス欄をクリック | カーソルが移動する |
| 数値キーを入力 | 16進数でデータが入力される |
| Enter キー | 次のアドレスに移動する |
| Esc キー | 編集をキャンセルする |
| Ctrl + Z | 元に戻す |

---

## 補足

- バージョンによってメニューの場所が若干異なる場合がある
- バージョン確認：**ヘルプ → バージョン情報**
- うまく開けない場合はスクリーンショットを共有すると対応しやすい
