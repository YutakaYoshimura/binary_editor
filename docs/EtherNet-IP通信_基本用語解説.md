# EtherNet/IP通信 基本用語解説

## Class1(クラス1通信)

I/Oデータを一定周期で自動的に送受信し続ける通信である。一度接続を確立すれば、以降は都度要求せずとも設定された間隔でデータが継続的に流れる。通信方式には速度を優先する方式(UDP)を用いており、リアルタイム性の高い制御データのやり取りに適している。用途としては、PLCとI/Oデバイス間における制御データの交換が挙げられる。

## Class3(クラス3通信)

必要な都度、要求を送信し応答を受け取る形式の通信である。1回の要求と応答でやり取りが完結する。通信方式には信頼性を優先する方式(TCP)を用いており、正確なデータ伝達が求められる場面に適している。用途としては、パラメータ設定や診断情報の取得など、非周期的なデータ交換が挙げられる。

## API(Actual Packet Interval)

デバイス間で実際にデータが送受信されている間隔の実測値である。後述するRPIで設定した周期に対し、実際の通信がどの程度の間隔で行われているかを示す指標となる。

## RPI(Requested Packet Interval)

データの更新周期として要求する設定値である。単位はミリ秒であり、例えば「RPI=10ms」と設定した場合、10ミリ秒ごとにデータを更新・送信するよう要求することを意味する。通信負荷や制御精度を左右する重要な設定項目である。

## スキャナ(Scanner)

通信における親局であり、他のデバイスに対して周期的なデータの送信を要求し、データの収集および制御を行う機器である。PLC本体やEtherNet/IPマスターユニット等が該当する。

## アダプタ(Adapter)

通信における子局であり、スキャナからの要求に応じて実際にI/Oデータを提供する機器である。I/Oユニット、センサー、インバータ等のフィールド機器が該当する。

## オリジネーター(Originator)

Class3通信において、要求を送信する側である。Class1におけるスキャナに相当する役割を担う。

## ターゲット(Target)

Class3通信において、要求を受けて応答を返す側である。Class1におけるアダプタに相当する役割を担う。
