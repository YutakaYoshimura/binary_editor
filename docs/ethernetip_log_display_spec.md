# EtherNet/IP診断ツール ログ表示仕様

## 基本方針
コネクション一覧・パラメータ・入出力データは別項目で表示するため、
ログ表示は「いつ・どのデバイスで・何が起きたか」を記録する
**時系列のイベント履歴**に特化する。

---

## 1. 基本情報(各ログ行)

| 項目 | 内容 |
|---|---|
| タイムスタンプ | ミリ秒単位推奨(周期のズレ確認のため) |
| 対象デバイス名/IPアドレス | どの接続のログか識別するため |
| ログレベル | INFO / WARNING / ERROR |

---

## 2. モニタ操作関連

- モニタ開始
- モニタ停止
- 設定変更(監視対象の追加・削除など)

---

## 3. 接続イベント(出来事のみ)

- 接続確立の発生
- 切断の発生
- タイムアウトの発生
- リトライの発生(何回目か)

※ 現在の接続状態そのもの(Established/Closingなど)は別表示側の担当のため、ログには含めない。

---

## 4. エラー系

- CIP General Status コード + 意味のテキスト
  - 例: `0x01 Connection failure - タイムアウト`
- Extended Status コード(存在する場合)
- エラー検出元(送信側 / 受信側)

---

## 5. ログ運用機能

| 機能 | 内容 |
|---|---|
| レベル別フィルタ | INFO / WARNING / ERROR の表示切替 |
| デバイス別フィルタ | 特定デバイスのログのみ抽出 |
| 連続エラーのまとめ表示 | 例:「タイムアウト ×5回」としてカウント集約(ログ埋もれ防止) |
| CSVエクスポート | ログの外部出力 |
| 自動スクロール ON/OFF | ログ流れている最中に固定して見たい場合用 |

---

## 優先度メモ
「タイムスタンプ + イベント種別 + ステータスコード(意味付き)」の3点が
現場での一次切り分けに直結するため、実装優先度は最も高い。
