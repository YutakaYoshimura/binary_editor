# バイナリディタ実現手段の整理（.NET Framework 4.8 / WinForms）

本ドキュメントでは、  
**バイナリディタ（Hex Editor）を実現するための OSS および有償パッケージ**について、  
以下の観点で整理する。

*   OSS かどうか
*   ライセンス形態
*   商用利用可否と必要手順
*   .NET Framework 4.8 対応有無
*   WinForms アプリとして利用可能か

***

## 各パッケージ詳細

***

### Be.HexBox

*   **OSS**：Yes
*   **ライセンス**：MIT License
*   **対応**：.NET Framework 4.8 / WinForms
*   **特徴**
    *   WinForms でそのまま使える Hex Editor コントロール
    *   実装工数が最小
*   **商用利用時の手順**
    *   著作権表示を保持
    *   MIT License 本文を配布物に同梱
*   **不要**
    *   ソース公開義務
    *   利用料

***

### WPFHexaEditor / HexEditor.Wpf

*   **OSS**：Yes
*   **ライセンス**：Apache License 2.0
*   **対応**：.NET Framework 4.8
*   **WinForms**：不可（※ WindowsFormsHost 経由なら可）
*   **特徴**
    *   高機能（Undo/Redo、検索、ハイライトなど）
    *   本体は WPF 前提
*   **商用利用時の手順**
    *   Apache 2.0 LICENSE を同梱
    *   NOTICE ファイルを保持
    *   改変した場合はその旨を明示
*   **補足**
    *   Apache 2.0 には特許ライセンス条項あり

***

### Spooksoft.HexEditor

*   **OSS**：Yes
*   **ライセンス**：MIT License
*   **対応**：.NET Framework 4.8
*   **WinForms**：不可（WPF 専用）
*   **特徴**
    *   軽量・シンプルな Hex Editor
*   **商用利用時の手順**
    *   MIT License 本文と著作権表示の保持のみ

***

## 有償パッケージ（Hex Editor を「作る」アプローチ）

***

### C1FlexGrid

*   **提供元**：ComponentOne（Mescius）
*   **ライセンス**：商用（プロプライエタリ）
*   **対応**：.NET Framework 4.8 / WinForms
*   **位置づけ**
    *   Hex Editor 専用ではない
    *   グリッドを使って **自作 Hex Editor を実装**
*   **向いているケース**
    *   業務 UI との統一
    *   商用サポート必須
*   **注意**
    *   Undo / 検索 / バイト同期などは全て自前実装

***

### DevExpress / Telerik / Syncfusion

*   **共通点**
    *   商用 UI コンポーネント
    *   .NET Framework 4.8 / WinForms 対応
*   **特徴**
    *   高性能・高自由度
    *   Hex Editor 機能は標準では存在しない
*   **位置づけ**
    *   C1FlexGrid と同じく「素材」

***

## 有償・専用 Hex Editor

### Hex Editor Neo SDK

*   **ライセンス**：商用独自
*   **対応**：.NET Framework 4.8 / WinForms
*   **特徴**
    *   高機能 Hex Editor を SDK として提供
    *   実装工数が最小
*   **注意**
    *   ライセンス費用は比較的高い

***

## 選定指針（結論）

*   **WinForms + .NET Framework 4.8 で素早く実装**
    *   → Be.HexBox / Hex Editor Neo SDK
*   **業務アプリに埋め込み・商用サポート重視**
    *   → C1FlexGrid / DevExpress / Telerik
*   **Hex Editor 機能が主用途**
    *   → 専用 Hex Editor（OSS または SDK）

***

必要であれば次に対応できます：

*   ✅ **最終推奨案（用途別）**
*   ✅ **コスト・工数・リスク比較表**
*   ✅ **OSS 利用申請書／NOTICE 用テンプレ**

どこまで使う想定かに合わせて、さらに絞り込みます。
