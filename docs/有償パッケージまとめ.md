# バイナリエディタ コントロール調査まとめ

## 開発環境・要件

- **開発環境：** .NET Framework 4.8 / WinForms
- **要件①：** バイナリデータを全て表示し修正する画面の実装
- **要件②：** DataGridView上にバイナリデータのパラメータ一覧を表示し、バイナリデータをクリックしたら編集状態に切り替わり値の編集ができる画面

---

## 実現方法の2タイプ

| タイプ | 概要 |
|---|---|
| **タイプ①** | グリッドコントロールのカスタムセルエディタ機能を活用してバイナリ編集を実現する |
| **タイプ②** | バイナリ/Hexエディタのコントロールそのものを提供するパッケージを使う |

---

## タイプ①：有償グリッドコントロール候補

### 共通の実現方針
- グリッドの各行にバイナリパラメータ（名称・オフセット・値・型など）を列として表示
- セルクリック時にカスタムのHex入力エディタに切り替わるよう実装
- 各グリッド製品が提供するカスタムエディタAPIを利用する

## タイプ②：バイナリ/Hexエディタコントロールそのものを提供するパッケージ

### 調査結論
DevExpress・Telerik・Syncfusion・Infragistics・MESCIUS等の主要商用ベンダーは、いずれもバイナリ/Hexエディタコントロールをラインナップに含めていない。

有償専用製品として確認できたのは以下の1製品のみ。

### Codejock Suite Pro for ActiveX

| 項目 | 内容 |
|---|---|
| **発売元** | Codejock Software |
| **価格** | $881.02〜（ComponentSource経由） |
| **HexEditコントロール機能** | アドレス表示・Hex/ASCII/バイナリ表示・編集・色設定・読み取り専用設定・行あたりバイト数指定 |
| **.NET 4.8 WinForms対応** | △ COM Interop（AxHost）経由で利用可能 |
| **注意点** | Visual C++ MFC / ActiveX COM ベースの製品のため、WinFormsへの組み込みにはCOM Interopの実装が必要。純粋な.NETネイティブコントロールではない |
| **入手先** | codejock.com / componentsource.com |

## HexEditorNeo（HHD Software）について

当初候補として挙がっていたが、要件を満たさないことが判明。

| 項目 | 内容 |
|---|---|
| **製品の性質** | Windowsスタンドアロンのバイナリエディタアプリケーション |
| **SDK提供** | ActiveX/COMおよび.NETコンポーネントによるAPIは提供しているが、あくまでデータ処理機能のAPIであり、WinFormsに埋め込めるUIコントロールは提供していない |
| **結論** | **要件を満たさない** |

## 要件別の推奨アプローチ

| 要件 | 推奨アプローチ | 推奨製品 |
|---|---|---|
| **要件①：バイナリデータ全表示・修正画面** | タイプ② または タイプ①グリッドの全バイト表示モード | Codejock Suite Pro（有償・COM Interop要）|
| **要件②：パラメータ一覧＋クリック編集** | タイプ①グリッドのカスタムセルエディタ活用 | C1FlexGrid・DevExpress・Telerik・Infragistics・10Tec iGrid.NET など |
| **①②を1パッケージで揃えたい** | Codejock Suite Pro（GridコントロールとHexEditコントロールの両方を同梱） | Codejock Suite Pro（COM Interop実装が前提） |

## 今後の検討ポイント

- COM Interop（Codejock）の採用可否をアーキテクチャ上で判断する
- タイプ①グリッドを採用する場合、要件①の全バイナリ表示画面をどう実装するか別途設計が必要
- 各製品の評価版（無料トライアル）で実際の動作を確認することを推奨
