# バイナリエディタ開発案件 調査まとめ

---

## 1. バイナリエディタとは

ファイルのデータを**バイナリ（2進数）や16進数（Hex）で直接閲覧・編集するツール**。通常のテキストエディタは人間が読めるテキストとして表示するが、バイナリエディタはファイルの生のバイトデータをそのまま扱う。

---

## 2. 主な用途

| 用途 | 説明 |
| --- | --- |
| ソフトウェア開発・デバッグ | コンパイル済み実行ファイルや通信プロトコルのパケットデータ解析 |
| ファイル修復・解析 | 破損ファイルの修正、マジックナンバー（ファイル形式の識別子）の確認 |
| リバースエンジニアリング | ソフトウェアやファームウェアの内部構造調査 |
| ゲーム改造（ROM hack） | ゲームデータの数値書き換えによるパラメータ変更 |
| セキュリティ調査 | マルウェア解析、実行ファイルへの脆弱性調査 |

---

## 3. 一般的な機能一覧

### 表示関連
- 16進数（Hex）表示と対応するASCII文字の並列表示
- オフセット（アドレス）表示
- 10進数・8進数など表示形式の切り替え

### 編集関連
- 任意のバイトを直接書き換え
- バイト列の挿入・削除
- コピー＆ペースト

### 検索・解析関連
- 特定のバイト列やテキスト文字列の検索・置換
- データ構造の可視化（構造体ビュー）
- エンディアン（バイト順）を考慮した数値解釈

### その他
- 差分比較（2ファイル間のバイト差を比較）
- チェックサム・ハッシュ計算（MD5、SHA1など）
- ディスクやメモリの直接読み書き（高機能製品）

## 5. 必須機能の詳細解説

### 検索・置換
- **何をするか**: 特定のバイト列や文字列をファイル全体から探し、必要であれば別の値に書き換える
- **なぜ必要か**: 巨大なファイルを目視で探すのは不可能なため。`FF FF` のようなバイト列で検索する

### 差分比較
- **何をするか**: 2つのファイルを並べて、異なるバイトをハイライト表示する
- **なぜ必要か**: 「設定変更前後でファイルのどこが変わったか」を調べる際に必須

### スクリプト・マクロ自動化
- **何をするか**: 決まった編集作業をコードで自動実行できる
- **なぜ必要か**: 同じ編集を何十・何百ファイルに繰り返す場合、手動では現実的でないため

### 構造体定義・テンプレート機能
- **何をするか**: バイト列にラベルを付けて人間が読める形で表示する
- **なぜ必要か**: 構造が分かっているファイル形式を解析する際の効率が大幅に上がるため

### チェックサム・ハッシュ計算
- **何をするか**: 選択データのMD5・SHA1・CRC32などを計算・表示する
- **なぜ必要か**: ①ファイルの正常転送の検証、②バイナリ書き換え後に埋め込まれたチェックサム値の更新

### エンディアン対応
- **何をするか**: ビッグエンディアン・リトルエンディアンを切り替えて数値を表示する
- **なぜ必要か**: CPUアーキテクチャによってバイトの並び順が異なるため。組込み・ネットワーク解析では必須

### 機能別 難易度・優先度

| 機能 | 難易度 | 特に必要な案件 |
| --- | --- | --- |
| 検索・置換 | 低〜中 | ほぼ全案件 |
| 差分比較 | 中 | 解析・改造系 |
| エンディアン対応 | 低 | 組込み・通信系 |
| チェックサム計算 | 低〜中 | 組込み・改造系 |
| スクリプト自動化 | 高 | 大量ファイル処理 |
| 構造体テンプレート | 高 | 専門的な解析系 |

## 6. 提案時の注意点

- **スコープを明確に合意する**: バイナリエディタは機能追加が際限なくできるため、MVP（最小限の製品）と将来拡張を明確に分けて提案する
- **大容量ファイル対応は工数が跳ね上がる**: 数GB以上を扱う場合、メモリマップや遅延読み込みなど設計が複雑になる点を早めに共有する
- **競合ツールとの差別化を言語化する**: 「なぜ既存ツール（HxD・010 Editorなど）ではなく新規開発するのか」を整理しておく
- **有償パッケージの選択肢がない点をあらかじめ説明する**: Hexエディタ専用の商用NuGetパッケージは市場に存在しないため、OSSをベースに開発するか一から自社実装するかを早期にすり合わせる

## 9. Windowsで使える一般的なバイナリエディタ ツール一覧

開発案件の機能検討・参考として実際に触れるスタンドアロンツールです。

### 【無償ツール】

#### HxD
- **URL**: https://mh-nexus.de/en/hxd/
- **OS**: Windows専用
- **商用利用**: ✅ 可能
- **特徴**: 最もポピュラーな無償ツール。ファイル・RAM・ディスクの編集に対応。検索・置換、チェックサム計算、ファイル分割・結合など基本機能がすべて揃っている
- **向いている用途**: 初めてHexエディタを触る人・シンプルに使いたい人

#### ImHex
- **URL**: https://imhex.werwolv.net/
- **OS**: Windows / macOS / Linux
- **商用利用**: ✅ 可能（GPLv2）
- **特徴**: 無償でありながら有償製品に匹敵する高機能。C++ライクなパターン言語でファイル構造を定義して自動ハイライト・解析ができる。逆アセンブラ・エントロピーグラフ・差分比較・ダークテーマも搭載。積極的に更新中
- **向いている用途**: リバースエンジニアリング・マルウェア解析・ファームウェア解析・開発案件の機能調査

#### Hex Editor Neo（Free版）
- **URL**: https://freehexeditorneo.com/
- **OS**: Windows専用
- **商用利用**: △ 基本機能のみ無償（上位機能は有償）
- **特徴**: 超大容量ファイルの高速処理に特化。正規表現対応の検索・置換、32bit/64bitパッチ作成機能を持つ
- **向いている用途**: 1GB〜TB級の大容量ファイルを扱う必要がある人

### 【有償ツール】

#### 010 Editor
- **URL**: https://www.sweetscape.com/010editor/
- **OS**: Windows / macOS / Linux
- **価格**: 有償（30日間試用可）
- **特徴**: バイナリテンプレート機能が最大の強み。C言語に似た構造定義でファイルを階層ツリーとして可視化できる。80種以上のフォーマットに対応したテンプレートが公式リポジトリで配布されており、C言語ライクなスクリプトで作業を自動化できる
- **向いている用途**: 独自バイナリフォーマットの解析・定期作業の自動化が必要なプロフェッショナル向け

#### WinHex
- **URL**: https://www.x-ways.net/winhex/
- **OS**: Windows専用
- **価格**: 有償（複数ライセンス体系あり）
- **特徴**: デジタルフォレンジック・データ復旧・ディスク解析に強みを持つ。ディスクのクローン・イメージ作成、削除ファイルの復旧、暗号化・復号化など専門的な機能が充実
- **向いている用途**: セキュリティ専門家・デジタルフォレンジック担当者向けの業務ツール
